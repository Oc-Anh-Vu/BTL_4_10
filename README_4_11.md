## 1. Ý hiểu về bài toán dự án
- Dự án **"Hôm nay ăn gì"** là dự án mang những công dụng và tiện lợi được lấy theo ý tưởng nhanh gon của Tinder nhưng theo định hướng về ẩm thực.
- Dự án được hình thành để giải quyết 1 nhu cầu hiện nay của người trẻ **sự nhanh gọn trong việc đưa ra sự lựa chọn** hoặc có thể nói theo góc nhìn khách quan hơn là **Lười suy nghĩ**.

## 2. Công nghệ sử dụng trong dự án
*   **Frontend:** 
- Sử dụng mô hình Vite + React + TypeScript + Tailwind CSS
- Thư viện bổ trợ: Framer-motion, Socket.io-client / SockJS-client.
*   **Backend:** 
- Sử dụng framework Java Spring Boot.
- Mô hình kiến trúc phân lớp (Controller - Service - Repository).
*   **Database:** 
- Sử dụng hệ quản trị PostgreSQL làm lữu trữ chính.
*   **Tools:** 
- Quản lý các Source Code bằng Git/GitHub.
